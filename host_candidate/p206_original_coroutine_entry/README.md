# P206 — genuine original Kotlin boot coroutine `invokeSuspend` entry on Android 35

P205 already proved the original `MainActivity.bootEngine()V` method was reached naturally from the original `MainActivity.onCreate` on Android35, using a single ephemeral method-entry witness. P206 probes the **next distinct method**, the exact original `Lcom/dsh/android/MainActivity$bootEngine$1;->invokeSuspend(Ljava/lang/Object;)Ljava/lang/Object;`, without manually calling it, scheduling a synthetic coroutine or starting Node.
