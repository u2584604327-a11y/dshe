# P156 correct-UID private-lib read-only audit

P155 shell UID 2000 could not open the staged original libz.so.1 under synthetic /data/data/com.termux. P156 only inspects *pre-existing* files/termux/usr/lib/libz.so.1 and libcares.so from the same-package com.dsh.android Activity process in the disposable P143 emulator. It checks package, ApplicationInfo UID, private-file canonical containment, bounded bytes, and ELF machine category. It never writes, chmods, executes or loads library/Node, starts an engine, opens a network connection, or prints private paths/file bytes. ABSENT is a valid diagnostic outcome on x86_64 with no matching original bootstrap. Readable ELF does NOT establish source hash, loader namespace or production Node readiness; only a real ARM64 correct-UID test can further advance those claims. User phone, original installed APK, signing, accounts, P109 DENY_ALL and Draft PR #80 remain untouched.
